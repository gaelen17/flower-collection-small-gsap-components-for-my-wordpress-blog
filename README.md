# flower-collection-small-gsap-components-for-my-wordpress-blog
A collection of responsive SVG floral components with GSAP animations for WordPress.

Responsive SVG floral components with CSS halo glow effects and GSAP animations for Gutenberg/WordPress.

🌿✨ Floral SVG & GSAP Components Collection 🌸

A lightweight, modular collection of responsive SVG floral components featuring ambient CSS halos and subtle GSAP animations. Crafted specifically for WordPress (Gutenberg) and custom creative web projects.

📂 Collection Overview

- **`01-frise-fleurs/`** — Responsive horizontal floral garland with a soft ambient halo.
- **`02-couronne-fleurs/`** — Circular floral crown featuring an isolated halo background and smooth GSAP rotations.

🚀 How to Use

1. Browse to any component folder (`01-frise-fleurs` or `02-couronne-fleurs`).
2. Copy the HTML/CSS/JS code from `index.html`.
3. Paste directly into a WordPress **Custom HTML** block or any standard HTML document.

🛠️ Features

- **Fully Responsive:** Vector graphics that scale cleanly on mobile and desktop.
- **Isolated Scopes:** CSS classes and JavaScript variables are scoped to prevent styling conflicts between components.
- **GSAP Powered:** Organic, smooth animations.
- **Lightweight:** No bloated frameworks or unnecessary dependencies.
